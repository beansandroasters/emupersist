# Security policy

Please do not report security issues in public issues.
Report them through GitHub's private vulnerability reporting instead:
**Security** tab → **Report a vulnerability** on this repository.

emupersist is a development and testing tool. Please read the
[Security section of the README](README.md#security) for what it does and does not protect against
(for example, the emulator behind it does not verify signatures).

Supported versions: only the latest release on the `main` branch receives fixes.
